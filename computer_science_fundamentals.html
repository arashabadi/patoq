4.5 Version Control: Git and GitHub

4.5.1 Why It Matters

Git helps you track changes, collaborate safely, and recover from mistakes without losing your work history.

4.5.2 Core Concepts

  • Repository: your tracked project folder
  • Commit: a saved checkpoint
  • Branch: an isolated line of work
  • Pull Request: proposed changes for review

4.5.3 Quick Command Workflow

# Clone project and create a feature branch
git clone https://github.com/username/repository.git
cd repository
git checkout -b feature/your-topic

# Work, commit, and push
git status
git add .
git commit -m "Add your update"
git pull --rebase
git push -u origin feature/your-topic

4.5.4 Beginner-Safe Recovery Patterns

# Unstage a file (keep edits)
git restore --staged path/to/file

# Discard local edits in one file
git restore path/to/file

# Revert a bad commit with a new safe commit
git revert <commit_hash>

# Temporarily save unfinished work
git stash push -m "wip: notes"
git stash pop

Avoid destructive commands (for example git reset --hard) unless you fully understand the impact.
